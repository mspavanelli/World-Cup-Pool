# Acesso por link de e-mail

A pessoa acessará a aplicação por um link enviado ao seu e-mail, que também verifica o endereço usado para identificá-la. Essa opção evita gerir senhas e não exige conta em um provedor externo, ao custo de depender da entrega de e-mails; durante o desenvolvimento local, uma caixa de testes em Docker receberá as mensagens. O serviço de envio para uma futura publicação ainda será escolhido.
